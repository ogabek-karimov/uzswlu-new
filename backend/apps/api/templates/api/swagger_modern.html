Universitet sayti API

Sayt (Nuxt), Vue admin panel va xodim kabineti uchun yagona API. Barcha matnlar 4 tilda qaytadi, kirish huquqlari rol bo‘yicha boshqariladi.

… amal 4 til: uz · ru · en · zh 5 rol OpenAPI 3.1 (JSON)

1Ochiq API'ni sinang

Sayt ma’lumotlari. API_TOKEN bo‘sh bo‘lsa, sarlavha shart emas.

curl -H "Authorization: Bearer <API_TOKEN>" \ "__HOST__/api/home?lang=uz"

2Admin sifatida kiring

Javobdagi token — JWT, 8 soat amal qiladi.

curl -X POST __HOST__/api/cms/users/login \ -H "Content-Type: application/json" \ -d '{"username":"superadmin","password":"…"}'

3Tokenni ishlating

Swagger’da: pastdagi Authorize → panelJwt. Kodda:

curl -H "Authorization: Bearer <JWT>" \ "__HOST__/api/cms/posts?limit=10"
Ochiq sayt API’sibearerAuth — Authorization: Bearer <API_TOKEN>. Token backend/.env dagi API_TOKEN; bo‘sh bo‘lsa tekshirilmaydi. /api/site/* va /api/hit tokensiz ochiq.
Admin panel /api/cms/*panelJwt — login javobidagi JWT (yangilash: /users/refresh-token) yoki panelSession — brauzer cookie’si (yozishda Origin ruxsat etilgan bo‘lishi kerak).
Xodim kabineti /api/me*userSession — HEMIS orqali kirgan sessiya cookie’si, yoki staffBearer — issue_staff_session tokeni.

JWT muddati tugasa, hisob yopilsa yoki parol o‘zgarsa bekor bo‘ladi.

Ochiq sayt API’si

?lang=uz|ru|en|zh — til (tarjima bo‘lmasa o‘zbekcha). Ro‘yxatlarda ?page=1&perPage=12 (ko‘pi bilan 48).

__HOST__/api/posts?type=news&lang=ru&page=2&perPage=12

Admin panel API’si

limit, page, sort (-createdAt), depth va where[maydon][equals]=… filtri. Javob: docs, totalDocs, totalPages, hasNextPage.

__HOST__/api/cms/posts?where[type][equals]=news&sort=-publishedAt&limit=20&page=1
